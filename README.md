# 环耕站布点调整 & 检测工具

单文件、纯前端的环耕站布点（样点）检查与调整工具。用于黑龙江省耕地质量调查样点布设工作中的样点间距检查、疑似问题点替换/移动、格网组合检查及人工目视检查辅助。

## 在线访问

部署完成后访问：

**https://jinguo0201.github.io/HGZpointsFixingTool/**

## 功能

- 只读加载本地任务文件夹（01 省级样点、02 市县级样点、03 样点池、05 区县格网），不修改原始 SHP 文件；
- 自动识别任务组与行政区，严格按行政区匹配数据，避免跨区误判；
- 检查任意两个样点间距是否严格大于 1500 m，支持本区与同文件夹其他行政区联合检查；
- 在内存中替换或移动 02 市、县级样点：
  - Shift + 单击用 03 候选池点替换；
  - 按住 Space + 单击在 20 m 圆环内移动；
  - 省级 01 点强制锁定；
- 一键自动调整距离过近的样点；
- 地类替换规则：旱地与水浇地视为同一“旱地类”，可互相替换，但界面和导出属性仍保留各自地类名称；其他地类严格匹配；
- 自动调整优先同耕地等级：有 04 等级时优先同等级候选，其次相邻 ±1 级，再考虑其他/未知等级，同时保留同 05 格网优先；
- 05 格网组合检查：每个格网保持 1 省级 + 1 市级 + 1 县级；
- 候选点格网优先：选中问题点时优先显示同一 05 格网内的候选；同格网没有可替换候选时才开放其他格网，并弹出横幅提示；
- 候选点等级分级：同等级候选存在时只显示同等级；否则开放 ±1；仍没有才开放 ±2；同等级候选都不合格时可点“显示 ±1 级候选（增加可选点）”按钮逐级放宽，选择 ±2 级候选会弹窗提醒；
- GDDJBZ 备注：发生 ±2 级跨级替换的点，导出 02 DBF 时新增 GDDJBZ 字段并写入“跨多个耕地质量等级替换”；未跨级时字段结构不变；
- 候选点距离辅助圈：选中问题点后，鼠标悬停合格候选点会显示以候选点为圆心的 100 m / 200 m 亮品红色虚线指示圈（带白色描边）；
- 图层符号样式：省级/市级/县级/03 候选池/其他行政区点可切换 10 种形状，并用 RGB 色带或 RGB 代码改色；05 格网可设置边框粗细、边框颜色、填充颜色/无填充和透明度，默认关闭格网显示；
- 旱地耕地等级：从 04 耕地质量等级栅格读取（支持 8/16 位 GeoTIFF）；选择行政区后后台静默预读并缓存，悬停、选中点面板、目视检查面板显示等级，选中旱地时合格候选点上方标注等级；
- 目视检查模式：仅依次检查 02 市、县级样点（省级 01 点不进入检查队列），地图同时显示 100 m 蓝色圆环和 200 m 橙色高透明度指示圈，可逐点跳转，人工勾选林地重合、河流距离、侵蚀沟避让、田垄检查；面板内可开启编辑模式，直接替换或移动问题点；进入目视检查时若已开启编辑模式，会自动选中当前显示的问题点；目视检查中按住 Space 移动点时不放大地图，而是保持 100 m 视野并在点位显示黄色透明的 20 m 瞄准圈；
- 导出前自动校验目视检查进度：若仍有 02 市、县级点存在未勾选项，会阻止导出并打开独立的“待补充目视检查”悬浮面板；补充完成后合并回本次修改点集继续导出；
- 本地进度自动保存到浏览器（IndexedDB，降级 localStorage），按行政区恢复；
- 横幅提示：所有横幅从顶部探出、约 5 秒后自动收回；切换目视检查点时旧横幅若不适用会强制收回，仍适用则延长 5 秒；
- 行政区状态标签：行政区下拉列表中每个行政区名称前显示浅红“未开展”、浅黄“进行中”、浅绿“已完成”状态标签，随目视检查进度实时更新；
- 完成撒花：绿色和蓝色进度条同时填满且导出成功后播放约 5 秒彩带；蓝色进度条填满且全部行政区均已导出后，播放约 10 秒、数量更多的撒花动画。彩带逐渐飘落并随风翻转旋转，不阻塞操作；
- 二轮复核模式：可将 xlsx/xls/csv 问题清单直接拖入左侧目标框，也可点击按钮选择文件；自动扫描 06_一轮成果，按文件名中的行政区名称 + 市级/县级匹配一轮成果 SHP（重复文件会报错），复核样点基于一轮成果而非原始 02；匹配 sheet、区县、级别、样点编码、问题列；导入问题清单后，问题行政区状态显示“待修改”，样点信息直接显示具体问题，仅切换问题点复核，可选择预填意见或“其他情况”文字反馈；面板可开始编辑替换/移动问题点；复核导出可选择下载 ZIP 或导出到文件夹，包含全部市/县级 SHP、市/县分开的问题点 SHP 及 Sheet1 复核反馈表 XLSX；反馈表新增“替换后样点编号”列，记录替换后的候选池样点编号；
- 任务进度统计：结果面板上方绿条为本行政区目视检查进度，蓝条为当前任务组全部行政区总进度，条内显示“完成数 / 总数”；进入目视检查时底部面板默认收起，进度条和“收起/展开面板”按钮固定在显示区最下方，随勾选实时更新；面板支持带过渡动画的收起/展开；
- 省级点间距离特例：若所有间距不合格项均为省级点↔省级点，按全部通过处理，不显示红色违规提示；
- 导出新的 SHP 成果包（完整五件套 + 修改记录 + 校验报告），同时生成市县级样点 KML，可直接导入奥维等软件使用；
- 导出 ZIP 文件名和“导出到文件夹”的文件夹名称中包含明确的行政区名称；
- 样点个数核对：按《附件1 耕地质量长期定位调查监测任务分解表》匹配行政区，选择文件夹、切换行政区或导出时比对实际省/市/县三级样点个数；不一致会提醒但仍允许编辑、检查和导出；
- 导出宽容度：若仍有无法自动或手动解决的间距问题，会继续提示，但允许停止编辑并导出；导出说明和校验报告中会记录未解决项，便于人工复核；
- 打开页面时以弹窗公告本次更新内容，点击“明白了”关闭；
- 天地图 Web 墨卡托影像底图：间距调整阶段强制不加载；进入目视检查后，每切换一个目标点只加载该点默认缩放视野内影像一次，缩放后不自动加载；地图左上角“全图”按钮可手动重新加载当前视野。不自动预加载、不持久化存储瓦片；可填写多个 Key 顺序故障转移，不自动切换到经纬度投影 img_c 或静态图。

## 使用方式

1. 打开在线页面或下载 `index.html` 后双击打开；
2. 点击“选择任务文件夹”，选择包含 `01_省级样点`、`02_市县级样点` 的任务文件夹（人名文件夹）或其上一级目录；
3. 检查、编辑或目视检查完成后，点击“导出成果”生成新的 SHP 文件；
4. 如需更换电脑继续工作，可用“导出进度”保存 JSON，再在另一台电脑“导入进度”。

## 数据与隐私

- 所有计算均在浏览器本地完成，样点数据不会上传到服务器；
- 仓库中不包含任何实际样点数据；
- 天地图 tk 保存在本机浏览器；仓库不内置默认 Key，必须由使用者主动填入自己的浏览器端 tk 才能启用底图；可填写多个 Key，当前 Key 限流/报错时自动切换到下一个。请在自己的天地图控制台配置当前站点域名白名单。
