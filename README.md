# 环耕站布点调整 & 检测工具

单文件、纯前端的环耕站布点（样点）检查与调整工具。用于黑龙江省耕地质量调查样点布设工作中的样点间距检查、疑似问题点替换/移动、格网组合检查及人工目视检查辅助。

## 在线访问

部署完成后访问：

**https://jinguo0201.github.io/HGZpointsFixingTool/**

## 功能

- 只读加载本地任务文件夹（01 省级样点、02 市县级样点、03 样点池、05 区县格网），不修改原始 SHP 文件；
- 自动识别任务组与行政区，严格按行政区匹配数据，避免跨区误判；
- 检查任意两个样点间距是否严格大于 1500 m，支持本区与同文件夹其他行政区联合检查；
- 在内存中替换或移动 02 市、县级样点：
  - Shift + 单击用 03 候选池点替换；
  - 按住 Space + 单击在 20 m 圆环内移动；
  - 省级 01 点强制锁定；
- 一键自动调整距离过近的样点；
- 05 格网组合检查：每个格网保持 1 省级 + 1 市级 + 1 县级；
- 目视检查模式：仅依次检查 02 市、县级样点（省级 01 点不进入检查队列），地图显示 100 m 圆环，可逐点跳转，人工勾选林地重合、河流距离、侵蚀沟避让、田垄检查；面板内可开启编辑模式，直接替换或移动问题点；进入目视检查时若已开启编辑模式，会自动选中当前显示的问题点；目视检查中按住 Space 移动点时不放大地图，而是保持 100 m 视野并在点位显示黄色透明的 20 m 瞄准圈；
- 导出前自动校验目视检查进度：若仍有 02 市、县级点存在未勾选项，会阻止导出并打开独立的“待补充目视检查”悬浮面板；补充完成后合并回本次修改点集继续导出；
- 本地进度自动保存到浏览器（IndexedDB，降级 localStorage），按行政区恢复；
- 导出新的 SHP 成果包（完整五件套 + 修改记录 + 校验报告），同时生成市县级样点 KML，可直接导入奥维等软件使用；
- 导出 ZIP 文件名和“导出到文件夹”的文件夹名称中包含明确的行政区名称；
- 打开页面时以弹窗公告本次更新内容，点击“明白了”关闭；
- 卫星底图可在天地图和高德卫星影像之间切换；高德使用 JS API 卫星图层，自动完成 WGS84→GCJ-02 坐标转换；首次打开自动启用内置 Key 并隐式加载。

## 使用方式

1. 打开在线页面或下载 `index.html` 后双击打开；
2. 点击“选择任务文件夹”，选择包含 `01_省级样点`、`02_市县级样点` 的任务文件夹（人名文件夹）或其上一级目录；
3. 检查、编辑或目视检查完成后，点击“导出成果”生成新的 SHP 文件；
4. 如需更换电脑继续工作，可用“导出进度”保存 JSON，再在另一台电脑“导入进度”。

## 数据与隐私

- 所有计算均在浏览器本地完成，样点数据不会上传到服务器；
- 仓库中不包含任何实际样点数据；
- 天地图和高德 Key 都保存在本机浏览器；公开仓库中的默认 Key 可能被多人共用，正式使用时建议填写自己的 Key。高德官方 Web 服务“静态地图”不支持卫星图层，本工具使用高德 JS API 卫星图层；如 Key 类型受限，请在高德控制台创建 Web端（JS API）Key。
