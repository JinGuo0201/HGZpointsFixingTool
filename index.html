环耕站布点调整&检测工具 · 使用说明

v2.6 · 原数据只读、修改保存在内存、导出为新的 SHP 成果包

一、整体流程

  1. 点击"选择任务文件夹"，选择本人任务文件夹（含 01–05 子目录的那一层）；工具只读加载，不会写入原文件。
  2. 选择行政区，工具自动加载 01 省级点、02 市/县级点、03 样点池、05 格网，并做间距检查。
  3. 开启"编辑模式"，用 Ctrl+单击选中一条 02 问题点；Shift+单击 03 候选点替换；按住 Space+单击在 20 m 圆环内移动。
  4. 每次修改都会做间距、类型、20 m 半径校验，并写入修改记录。
  5. 点击"导出成果"：生成修改后的 02 SHP 五件套（新文件，不覆盖原文件）+ 修改记录 + 校验报告。

二、编辑规则

  • 01 省级样点强制锁定：即使在编辑模式下，也不能替换、移动或选中省级点；单击省级点会提示“强制锁定”。
  • 只有 02 图层可编辑；03/05 只读。
  • 旱地耕地等级：工具会读取 04 耕地质量等级栅格；鼠标悬停旱地点、选中样点面板、目视检查面板都会显示“耕地等级”；选中旱地问题点时，合格候选点上方会标注其耕地等级，便于优先选择同值/相邻等级候选。
  • Shift+单击替换：候选点必须与问题点地类一致，且与当前所有样点（含相邻行政区）间距严格大于 1500 m；不合格候选点会变灰并禁止选择。
  • 候选点格网优先：选中问题点后，若同一 05 格网内存在合格候选，只显示同格网候选；同格网没有可替换候选时，才开放其他格网候选，并弹出横幅提示，跨格网替换可能影响格网组合。
  • Space+单击移动：以当前点位为圆心、20 m 为半径显示可操作圆环；光标超出圆环会自动限制在圆环边界；移动后同样校验 1500 m 间距。
  • 每次修改都可撤销/重做；导出前可随时继续调整，原文件始终不变。
  • 存在“未导出”的修改时切换行政区或任务组，会弹出确认窗口；确认切换将丢弃未导出的内存修改。
  • 问题检查：点击顶部“问题检查”按钮，中央窗口会显示当前正在检查的行政区、点数、检查范围等信息，并强制至少显示 2 秒后给出检查结果。
  • 格网组合检查：修改后关闭“编辑模式”时，工具会逐一检查当前行政区每个 05 格网是否保持“1 省级 + 1 市级 + 1 县级”组合；通过会提示，未通过可选择“继续编辑”或“强制保存”。
  • 一键调整样点：对当前行政区自动查找因间距过近而冲突的 02 样点，从 03 候选池中选择同地类、与所有点保持 1500 m 以上的候选点进行批量替换，尽量优先落在原格网内。
  • 目视检查模式：仅依次检查本区 02 市、县级样点（省级点不进入检查队列），地图同时显示 100 m 蓝色圆环和 200 m 橙色指示圈（均为高透明度），并显示右侧悬浮面板，人工勾选“林地重合、河流距离、侵蚀沟避让、田垄检查（仅水田）”；面板内可开启编辑模式，用 Shift+单击替换或 Space+单击移动当前问题点；目视检查中按住 Space 移动时保持当前视野，并在点位上显示黄色透明的 20 m 瞄准圈，不跳转到 20 m 放大视图；完成后自动做一次间距复核，通过后会询问是否导出成果。
  • 天地图底图：仅使用 Web 墨卡托影像 img_w + 注记 cia_w，与当前地图视图和 WGS84 样点坐标一致；首次使用不预填密钥，需在“底图设置”中填写自己的天地图 tk 后才会启用。支持填写多个 Key 按顺序自动切换，并使用 IndexedDB 持久缓存瓦片（上限 450 MB）；经纬度投影 img_c 与 Web 墨卡托视图不直接兼容，工具不会自动切换。
  • 本地进度：编辑、目视检查勾选会自动保存到浏览器本地（IndexedDB，失败时自动降级到 localStorage）。重新选择同一任务文件夹时，会提示是否恢复上次的编辑状态；每个行政区各保存一份进度。也可用“导出进度 / 导入进度”保存为 JSON 文件。
  • 导出前目视检查校验：点击“导出成果”时，若本区仍有 02 市、县级点存在未勾选的目视检查项，会阻止导出并弹出提示；可打开独立的“待补充目视检查”悬浮面板，逐点补充完成后合并回本次修改点集继续导出。
  • 导出格式与命名：导出结果同时包含 SHP 五件套和市县级样点 KML（可导入奥维等软件）；ZIP 文件名与“导出到文件夹”的文件夹名称均包含行政区名称。
  • 导出宽容度：如果仍有无法自动或手动解决的间距问题，工具会持续提示，但允许停止编辑并继续导出；导出说明和校验报告会记录未解决的间距问题，请在最终成果中人工复核。
  • 样点个数核对：选择任务文件夹、切换行政区或导出时，会把实际省/市/县三级样点个数与《附件1 耕地质量长期定位调查监测任务分解表》的预期个数比对；不一致会弹窗提醒，但仍允许进入编辑、检查和正常导出，导出说明/校验报告会记录不一致情况。
  • 更新公告：打开页面时会弹窗列出本次更新内容，背景不可操作；点击“明白了”后关闭，同一版本同一公告不会重复弹出。

三、天地图底图

  • 底图默认关闭；间距调整阶段强制不请求、不加载、不存储任何瓦片，避免消耗 Key 额度。
  • 进入目视检查后，每切换到一个目标点，只加载该点在默认缩放下的当前视野影像一次；不加载注记，不随缩放或平移自动加载。
  • 可用地图左上角“全图”按钮手动重新加载当前视野全部影像（会消耗额度）；缩放后如需要继续查看，请再次点击“全图”。
  • 不自动预加载、不持久化存储瓦片；可填写多个 Key，按列表从上到下使用，当前 Key 限流/权限/网络报错时自动静默切换下一个。全部 Key 不可用时暂停 60 秒并提示，点击 ↻ 可立即重试。
  • 密钥可能绑定了域名白名单（如 jinguo0201.github.io）；本地双击打开或域名不符时底图可能加载失败，不影响检查和编辑。
  • 同一 Key 并发/高频请求可能触发天地图限流（HTTP 429，code 302010）；多 Key 可缓解但不能绕过天地图服务条款。
  • 建议在 HTTPS 页面（如 GitHub Pages）使用，以获得完整的地图加载能力。

四、成果与安全

  • 导出包中只包含被修改的 02 图层和记录文件；01/03/04/05 不会被修改。
  • 导出后建议用 ArcGIS/QGIS 打开核对，再按成果提交要求替换原文件。
  • 刷新页面会丢失未导出的内存修改，请及时导出。
